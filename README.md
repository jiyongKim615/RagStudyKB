
# 📘 RAG 세미나 (2025.11.25)
```markdown
2025년 AI Labs에서 진행하는 세 번째 세션입니다.
LLM 시대의 핵심 기술인 RAG(Retrieval-Augmented Generation)를 실전 중심으로 익히고,  
우리 조직의 문제를 어떻게 RAG로 해결할 수 있을지 감을 잡는 것이 목표입니다.
```

## 📍 1. 세미나 개요

이번 세미나는 다음 내용을 중심으로 진행됩니다:

- LLM + 프롬프트만 사용했을 때의 근본적 한계
- 왜 RAG가 실제 서비스/해커톤/사내봇의 기본 구조가 되는가?
- 문제 유형별 RAG 디자인 패턴 정리
- Agent RAG·Graph RAG·Self-RAG 등 고급 패턴 개념 소개
- 실습(Agent RAG 미니 실습 + Graph RAG 맛보기)

세션의 핵심 목표는 **실무에서 바로 적용할 수 있는 RAG 기본 골격 이해**입니다.

## 📚 2. 전체 구성 (1시간)

1. **오프닝 & 2026 해커톤 스토리 (5분)**  
2. **LLM 한계 & 왜 RAG인가 (10분)**  
3. **RAG 기본 개념 & 구조 (15분)**  
4. **문제 패턴 → RAG 패턴 매핑 (15분)**  
5. **RAG 디자인 패턴 치트시트 (10분)**  
6. **Q&A (5분)**  

중간에 **Agent RAG / Graph RAG 실습 코드**를 보여주는 데모가 포함.
